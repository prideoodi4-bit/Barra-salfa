# برا السالفة — بوت تلكرام عراقي

بوت جاهز للتشغيل بكروب تلكرام يدعم الأقسام (Forum Topics)، بواجهات عراقية، ١٨ تصنيفاً و٦٤٣ سالفة فريدة مع أسماء بديلة. إعدادات الوقت وعدد الأسئلة محفوظة بصورة مستقلة لكل كروب، ويعدّلها الأدمن فقط. مكتوب بـ Python 3.11 أو أحدث، بدون مكتبات خارجية. الملفات تتضمن الكود وبنك الكلمات واختبارات وقالب Docker.

**الحزمة ليست بوتاً منشوراً:** لا يوجد توكن أو اتصال بحساب تلكرام ضمنها. فُحصت محلياً باستخدام Telegram API بديل في الاختبارات؛ يلزم توكن BotFather وخادم واتصال بـ api.telegram.org لإجراء اختبار فعلي وتشغيلها.

## تشغيل سريع

على Linux أو macOS، من مجلد المشروع:

```bash
cp .env.example .env
```

افتح `.env` وضع توكن البوت من `@BotFather` أمام `BOT_TOKEN`. لا تضعه في بنك الكلمات أو مستودع عام.

```bash
python3 bot.py
```

للعمل المستمر عبر Docker على خادم:

```bash
docker compose up -d --build
docker compose logs -f
```

قاعدة البيانات محفوظة في volume باسم `game-data` وتبقى بعد إعادة تشغيل الحاوية. لا تستخدم `docker compose down -v` إلا إذا أردت حذف البيانات. خذ نسخة احتياطية من البيانات؛ عند تشغيل Python مباشرةً توجد في `data/game.sqlite3` مع ملفات WAL المصاحبة، ويفضل النسخ أثناء توقف البوت.

يشغّل هذا المشروع نسخة واحدة للبوت عبر long polling. يمنع تشغيل عمليتين على نفس قاعدة البيانات. لا تشغّل نسختين بالتوكن نفسه، ولا تجمع هذا التشغيل مع webhook قائم؛ سيطلب البرنامج إزالة webhook بدلاً من تغييره تلقائياً.

## إعداد الكروب والقسم

1. أنشئ البوت بأمر `/newbot` لدى [BotFather](https://t.me/BotFather).
2. فعّل الأقسام في الكروب، وأنشئ قسماً مثل «🎭 برا السالفة» خارج القسم العام.
3. أضف البوت كأدمن، مع صلاحية إرسال الرسائل وحذف الرسائل. صلاحية الحذف تُستخدم عند فضح السالفة. البوت لا يحتاج صلاحية إنشاء أقسام؛ أنشئ القسم بنفسك.
4. احتفظ بوصول البوت لرسائل الكروب بصفته أدمن. إذا شغّلته بدون أدمن فلن يكون فحص العضوية أو التقاط الأسئلة والأجوبة مضموناً؛ كما أن حذف الكلمات المكشوفة سيفشل. خيار `/setprivacy` لدى BotFather → Disable بديل لقراءة الرسائل، لكنه لا يعوّض صلاحيات الأدمن المطلوبة لهذا الإعداد.
5. أدمن الكروب يكتب `/bind` **داخل القسم المخصص** مرة واحدة.
6. اكتب `/game` داخل نفس القسم. كل لاعب يفتح زر الانضمام بالخاص ويضغط Start؛ هذا شرط تلكرام قبل أن يتمكن البوت من مراسلته.

البوت يصمت في القسم العام والأقسام غير المرتبطة، باستثناء أمر `/bind` الصريح في قسم غير عام لتغييره بواسطة الأدمن. لا يحوّل رسائل اللعبة إلى القسم العام إذا القسم المخصص انغلق أو انحذف. يوجد قسم مرتبط واحد وكيم نشط واحد لكل كروب. يمكن لكروبات مختلفة اللعب بصورة مستقلة، لكن اللاعب لا يدخل كيمين بنفس الوقت حتى لا تختلط رسائله الخاصة.

## تدفق الكيم

1. المضيف يفتح لوبي، وكل لاعب ينضم من رابط الخاص. العدد ٣–١٢ لاعباً. مهلة اللوبي ١٥ دقيقة.
2. المضيف يختار التصنيف؛ ترتيب التصنيفات عشوائي. الأرقام بجانبها تعرض الكلمات غير المستخدمة.
3. تُسحب سالفة عشوائية من الكلمات غير المستخدمة بالكروب، ويُختار لاعب عشوائي برا السالفة.
4. الكل يستلم الدور بالخاص: اللي داخل يعرف الكلمة، واللي برا يعرف التصنيف فقط. كل لاعب يضغط «قريت دوري وجاهز» خلال دقيقتين. عدم جاهزية الجميع يلغي الكيم بدون نقاط.
5. البوت يختار أزواجاً عشوائية ويسوي تاگ للطرفين بالقسم. الأول يسأل الثاني، ثم يتبادلون الأدوار في السؤال التالي. لا يحتسب جواباً قبل سؤال الطرف المحدد. الكلام الجانبي لا يقدّم الدور، لكنه يبقى خاضعاً لكشف الكلمة.
6. الافتراضي ١٢ سؤالاً و٣٥ ثانية **للسؤال وجوابه معاً**. إجابة الطرف المطلوب تنقل الدور فوراً؛ انتهاء الوقت يتجاوز السؤال. كل اتجاه في الزوج يُحسب سؤالاً، لذلك ١٢ سؤالاً تعني ٦ أزواج تتبادل الأدوار، والحد الأعلى لوقت الأسئلة ٧ دقائق بالإعداد الافتراضي. يتكرر اللاعبون عند الحاجة للوصول إلى العدد المحفوظ؛ العدد الفردي يجعل أحد اللاعبين يشارك أكثر بصورة عشوائية. إذا ضبطت أسئلة أقل من عدد اللاعبين فقد لا يسأل كل لاعب.
7. التصويت يصل بالخاص، لمدة ٦٠ ثانية. ممنوع التصويت لنفسك، والأصوات قابلة للتغيير حتى الإغلاق. لا يغلق التصويت مبكراً عند اكتماله.
8. صاحب أعلى عدد أصوات، إذا كان منفرداً وهو اللي برا، ينكشف ويحصل على محاولة تخمين واحدة بالخاص خلال ٣٠ ثانية. التعادل أو انعدام الأصوات أو اختيار شخص آخر ينجّيان اللي برا.
9. تظهر الكلمة واللي برا وحصيلة التصويت ونقاط الجولة داخل نفس القسم. هويات المصوّتين لا تنكشف.

## التخمين وفضح الكلمة

- اللي برا يستخدم `/guess الكلمة` بالخاص أثناء الأسئلة: محاولة واحدة، الصحيح ينهي الجولة بفوزه، والخطأ ينهيها لصالح اللي داخل.
- إذا كتب اللي برا الكلمة الصحيحة أو اسماً بديلاً لها أثناء الأسئلة بالقسم، تُحسب تلقائياً كتخمين صحيح، حتى لو كتبها ضمن جملة. النص المطابق بالخاص يُحسب أيضاً.
- في فرصة التخمين الأخيرة، يكتب الكلمة وحدها بالخاص أو يستخدم `/guess الكلمة`. الخطأ يستهلك المحاولة؛ انتهاء الوقت يعتبر خطأ.
- إذا أحد اللي داخل كتب الكلمة أو اسماً بديلاً لها بالقسم، حتى ضمن `/guess`، تُلغى الجولة بدون نقاط ويُطلب حذف الرسالة. يبقى حذف الرسالة معتمداً على صلاحية البوت؛ الكلمات غير المعروفة للبنك والتلميحات غير المباشرة لا يمكن اكتشافها آلياً.
- تُقرأ الرسائل النصية الجديدة فقط. تعديل الرسائل والرسائل الصوتية والصور والملصقات لا تُحسب كأسئلة أو أجوبة أو تخمينات. اتفاق اللاعبين على عدم استخدام التعديلات أو الوسائط لفضح السالفة ضروري.

## النقاط

| نتيجة الجولة | نقاط اللي برا | نقاط البقية |
|---|---:|---|
| نجا من التصويت، بما فيها التعادل | ٣ | ٠ |
| انكشف وخمّن صح بالفرصة الأخيرة | ٢ | ١ لكل من صوّت عليه |
| انكشف وخمّن غلط أو انتهى الوقت | ٠ | ٢ لكل من صوّت عليه |
| خمّن صح أثناء الأسئلة | ٣ | ٠ |
| أعلن تخميناً خاطئاً أثناء الأسئلة | ٠ | ٢ لكل لاعب داخل السالفة |
| إلغاء أو فضح من لاعب داخل | ٠ | ٠ |

النقاط تراكمية لكل كروب، وليست مشتركة بين الكروبات. هذا نظام ثابت للنسخة المبنية، مبني على نظام سهرة مع قاعدة صريحة للتخمين المبكر.

| `/leave` | الخاص | خروج من اللوبي قبل توزيع الأدوار |

## بنك الكلمات ومنع التكرار

`words.json` يحتوي ٦٤٣ كلمة فريدة موزعة على ١٨ تصنيفاً. راجعنا البنك لتقليل الخيارات التخصصية: حذفنا ١٠٦ أسماء من النسخة الأولى، وأضفنا ٢٩ بديلاً أوضح، مثل داطلي وفشار وذرة وكمامة وحصالة ولعبة الثعبان. التقييم تحرير مقترح لجماعة عراقية عامة، وليس قياساً لمعرفة كل اللاعبين؛ تبقى بعض التصنيفات مثل الألعاب والأنمي اختيارية حسب الجماعة.

| التصنيف | عدد السوالف |
|---|---:|
| أكلات عراقية وأكلات البيت | ٤٠ |
| أكلات عامة وحلويات | ٤٠ |
| حيوانات | ٤٠ |
| فواكه وخضرة | ٤٠ |
| أغراض البيت | ٤٠ |
| ملابس وإكسسوارات | ٤٠ |
| مهن | ٤٠ |
| أماكن نروح إلها | ٤٠ |
| وسائل نقل | ٣١ |
| رياضات | ٢٦ |
| ألعاب فيديو | ٢٧ |
| كارتون وأنمي | ٣٤ |
| تطبيقات | ٢٤ |
| مدن عراقية | ٢٦ |
| دول | ٤٠ |
| مناسبات وفعاليات | ٣٥ |
| سوالف الطفولة | ٤٠ |
| مواقف يومية عراقية | ٤٠ |
| **المجموع** | **٦٤٣** |

`id` هو هوية الكلمة، و`text` عرضها العراقي، و`aliases` الأسماء المقبولة لنفس السالفة. رقي ورگي، مثلاً، ليسا جولتين مختلفتين. هويات الكلمات الـ٦١٤ المحتفظ بها من النسخة الأولى لم تتغير، ليستمر سجل عدم التكرار. الاسم «طباخ» محفوظ للمهنة، واستخدمنا «خلاط» ضمن أغراض البيت لتجنّب تكرار الاسم بمعنيين.

الحفظ يعتمد `(chat_id, word_id)`، حتى بعد تغيير اللاعبين أو إعادة التشغيل. السحب عشوائي من الكلمات غير المستخدمة، وليس تسلسلياً. الكلمات التي وُزعت أدوارها تعتبر مستخدمة حتى لو انلغت الجولة، لأن بعض اللاعبين عرفوها. لا إعادة تلقائية بعد نفاد البنك؛ الأدمن يؤكد إعادة التصنيف المستنفد أو يختار غيره.

تطبيع الكتابة يزيل التشكيل والتطويل ويوحّد همزات الألف وبعض الحروف العراقية، ويقبل بدائل واضحة إضافية. لا يستخدم تخميناً إملائياً ضبابياً، حتى لا يربح أحد على كلمة قريبة لكنها مختلفة. كشف الكلمات في الجمل يستخدم حدود كلمات حتى لا تُحسب «قط» داخل «قطار».

لتعديل أو توسيع البنك، عدّل `words_source.txt` وأضف البدائل في `bank.py`، ثم:

```bash
python3 bank.py
python3 -m unittest discover -s tests -v
```

يمكن تعديل JSON مباشرةً، لكن إعادة البناء تستبدله. حافظ على IDs القديمة للكلمات الموجودة حتى يستمر منع التكرار، وأوقف البوت قبل تغيير البنك. لا تحذف كلمة تستخدمها جولة نشطة. الأنمي والألعاب والتطبيقات وبعض الرياضات والمدن تحتاج اتفاق الجماعة أن يعرفون التصنيف.

## إعدادات كل كروب والترقية

الأدمن يكتب مثلاً `/settings 45 16` ليحفظ ٤٥ ثانية لكل سؤال وجوابه و١٦ سؤالاً قبل التصويت. أو يفتح `/settings` ويضغط أزرار زيادة/تقليل الوقت والأسئلة. المضيف الذي ليس أدمن لا يمكنه تغيير الإعدادات، سواء بالأمر أو بالأزرار. التصويت يبقى دقيقة والتخمين الأخير ٣٠ ثانية.

الإعدادات مخزونة في SQLite باسم الكروب، وتبقى بعد إعادة التشغيل وتغيير القسم المرتبط. كل كيم يأخذ نسخة من الإعدادات وقت `/game`؛ تعديلها أثناء لوبي أو جولة يحفظها للكيم التالي ولا يغيّر الجولة الحالية. عدد الأسئلة زوجي حتى كل زوج يسأل الطرف الآخر.

للترقية من النسخة الأولى: كمّل أو ألغِ أي كيم نشط، أوقف البرنامج، وخذ نسخة احتياطية من قاعدة البيانات، ثم استبدل ملفات الكود وبنك الكلمات فقط. احتفظ بـ `.env` و`data/` أو volume الحالي. جدول الإعدادات الجديد يُنشأ تلقائياً، والنقاط وسجل الكلمات السابقة يبقيان. الكلمات المحذوفة لا تُسحب مجدداً. لا تستبدل البنك أثناء جولة نشطة لأن سالفتها قد تكون ضمن الكلمات المحذوفة.

## الاختبارات والتشغيل

٣٧ اختباراً محلياً للتوجيه حسب القسم، سرية الأدوار والأصوات، صلاحيات المضيف والأدمن، الزوج العشوائي، الوقت، النتائج، التخمين المبكر والنهائي، الأسماء البديلة، نفاد الكلمات، استعادة البيانات، تكرار التحديثات، وحالات تعذر الإرسال، إضافة إلى استقلال إعدادات الكروبات وحفظها ومنع تعديلها من غير الأدمن وتطبيق العدد المحدد للأسئلة. لا تستعمل أي توكن أو كروب حقيقي.

قاعدة SQLite تخزّن انتقال اللعبة والنقاط والتحديث المستلم والرسائل الصادرة ضمن transaction واحدة. التحديث المكرر لا يكرر النقاط. الرسائل الصادرة لها retry عند أخطاء مؤقتة و429؛ لكن إرسال Telegram نفسه لا يوفّر مفتاح idempotency، لذلك قد تتكرر رسالة عرض فقط إذا انقطع البرنامج بعد إرسالها وقبل تسجيل نجاحها. الصلاحيات أو حظر الخاص أو إغلاق القسم يلغيان الجولة بدلاً من تغيير مكان الرسائل.

للتجربة الحقيقية: استخدم كروب اختبار بقسم عام وقسم لعبة و٣ حسابات على الأقل. افحص وصول الأدوار بالخاص، اسألوا وأجيبوا، صوّتوا، جرّبوا تخميناً صحيحاً وخاطئاً، وأعد تشغيل البوت للتأكد من بقاء النقاط وسجل الكلمات. اختبارات Docker والاتصال الحقيقي لم تُنفّذ ضمن بيئة إنشاء الحزمة.
